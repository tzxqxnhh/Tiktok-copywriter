# 抖音爆款文案生成工具 v1.1 版本报告

> 发布日期：2026-06-11

---

## 一、版本概述

v1.1 是抖音爆款文案生成工具的第二个正式版本，基于 v1.0 的五节点工作流架构，新增了**导演模式**（分镜脚本生成）和**自定义生成参数**两大核心能力。

**核心升级**：
- 导演模式：从"口播文案"升级为"分镜脚本"，5 种导演风格（剧情/痛点/悬念/干货/对比）各有独特的叙事框架和输出格式，用户拿到即可开拍
- 自定义参数：用户可自由选择文案风格组合和每种风格生成条数，不再受固定 3 条限制

**五种导演风格**：

| 风格 | 核心技法 | 叙事结构 |
|------|----------|----------|
| 剧情 | 以故事为壳，植入产品为魂 | 场景引入 -> 冲突/危机 -> 产品登场化解 -> 反转/惊喜 -> 购物车引导 |
| 痛点 | 精准人群 + 具体痛点场景 + 3秒扎心 | 痛点共鸣开头 -> 放大焦虑 -> 引出产品 -> 展示效果 -> 结尾 CTA |
| 悬念 | 用"没说完的话"制造好奇心缺口 | 神秘/反常开头 -> 层层铺垫 -> 意外反转揭晓 -> 产品露出 -> 结尾 CTA |
| 干货 | 内容是主体、卖货是顺带，建立信任感 | 抛出知识点 -> 分步骤演示 -> 纠正常见误区 -> 产品自然植入 -> 结尾 CTA |
| 对比 | "普通方案 vs 本产品"强烈反差 | 普通方案痛点展示 -> 产品登场 -> 实测对比 -> 性价比总结 -> 结尾 CTA |

```

开篇：丁佳疯狂踩着高跟鞋冲向公司，迟到了30分钟。
人物A（崩溃脸）：「完了完了，全勤奖泡汤了！」

冲突/危机：同事乐乐探过头来...
产品登场：丁佳递上泡好的枸杞水

反转/惊喜：BOSS喝了一口，脸色从阴转晴
结尾：快点击下方链接，开启从容生活！
（弹出购物车/屏幕字幕：限时优惠）
```

## 三、技术变更

### 3.1 修改文件清单

| 文件 | 变更类型 | 说明 |
|------|----------|------|
| `config.py` | 重构 | 删除 `DIRECTOR_SYSTEM_PROMPT`，新增 `DIRECTOR_STYLE_PROMPTS` 字典（5 套 prompt） |
| `workflow/node3_generator.py` | 重构 | `_build_prompt()` 重命名为 `_build_copywriting_prompt(styles, count)`；新增 `_build_director_prompt(director_style)`；`generate_copies()` 新增 `mode`/`styles`/`count`/`user_expectation`/`director_style` 参数 |
| `workflow/node5_scorer.py` | 增强 | `_build_scoring_prompt(mode, styles)` 动态化；`_format_copies_data(mode, styles)` 去除硬编码风格映射；容错 JSON 动态生成 |
| `main.py` | 增强 | `run_generation_workflow()` 新增 4 个参数；UI 新增 4 个组件 + 可见性回调；`_format_director_output()` 专用于分镜脚本渲染 |

### 3.2 新增配置常量

| 常量 | 类型 | 说明 |
|------|------|------|
| `DIRECTOR_STYLE_PROMPTS` | `dict[str, str]` | 5 种导演风格的独立 system prompt，每种 300-500 字 |

### 3.3 关键设计决策

1. **模式用字符串标识**：`mode="copywriting"` / `mode="director"`，可扩展
2. **统一返回类型**：两种模式都返回 `list[str]`，下游节点不受影响
3. **分镜脚本不强制解析**：`_format_director_output()` 直接渲染原始文本（5 种风格输出格式各异，强制结构化解析会损失表现力）
4. **所有新参数有默认值**：`mode="copywriting"`, `styles=None`, `count=3`, `user_expectation=None`, `director_style="剧情"`，保持向后兼容
5. **风格通过参数传递**：Node5 从参数获取风格名称，而非从文本解析，更可靠
6. **生成数量 = 每种风格各生成 N 条**：选择 2 种风格 + 数量=3 = 生成 6 条文案

## 五、已知限制

1. **分镜脚本依赖 prompt 质量**：5 种导演风格的输出质量取决于对应 prompt 模板的精准度，5 套 prompt 各自独立，后续可按风格独立调优
2. **max_tokens 限制**：当文案模式 count=10 且选择 5 种风格时（50 条），2048 tokens 可能不足以输出完整结果
3. **导演模式无数量控制**：导演模式每次只生成 1 条分镜脚本，不支持批量生成（符合设计预期——单条分镜脚本已足够详细）
4. **emoji 检测精度**：分镜脚本中使用了更多结构化的 emoji（如 🎬），现有正则模式需确保覆盖
